查找完整品牌库，继续查看套餐、线路和各品牌的独立 FAQ。

先阅读选购说明，再进入真实品牌资料核对设备、用量和计费条件。

2. 买之后：安装、配置与检查

拿到订阅以后，按设备选软件，再检查配置和实际连接。

客户端下载与选择 →

查看不同设备的客户端入口，核对软件来源与配置兼容。

用途：让设备能够读取品牌提供的订阅。

配置与隐私检测工具 →

生成订阅转换链接、检查 YAML 结构，并了解 WebRTC 与外部 DNS 测试。

用途：区分格式问题与连接问题，先了解工具的数据流向。

出口 IP 与 Base64 工具 →

查询出口 IP，或在浏览器内编码、解码 Base64 文本。

用途：辅助核对出口和订阅内容；解码后的凭据需要保管。

网页连通性检查 →

记录浏览器请求是否完成及耗时，再回到自己的应用复测。

用途：比较同设备、同目标的结果，辅助判断连接问题。

3. 想了解安全性：看原理与排查方法

线路名称、连接成功与隐私保护是不同问题，需要分别核对。

安全与网络研究入口 →

从协议、隐私和故障三个方向选择想了解的内容。

用途：把品牌资料中的技术名词与自己的使用条件联系起来。

隐私与防泄漏检查 →

了解订阅凭据、DNS、浏览器通信与第三方工具的信息流向。

用途：购买以后继续检查设备上的隐私设置。

协议与线路说明 →

理解 SS、VLESS、Trojan、Hysteria2，以及专线与 DNS 的基本概念。

用途：读懂品牌资料，核对客户端与协议是否匹配。

GFW 与节点故障判断 →

按 DNS、客户端、节点和网络做对照，保留可解释的故障记录。

用途：判断问题发生在哪一环，再决定是否需要调整服务。

4. 实际用途：AI、资源与资讯

先找到自己想完成的任务，遇到访问问题时再回到配置与排查。

AI 使用指南 →

按需求学习提问、查看图片示例，或查找 ChatGPT 与 Claude 的相关问题。

用途：把网络连接落实到自己的 AI 使用任务。

网站与资源书签 →

查看编程、设计和其他资源入口，选择自己需要访问的目标网站。

用途：找到实际使用场景，连接表现用自己的任务验证。

资讯与原始来源 →

查看资讯入口及来源链接，按自己的兴趣继续阅读。

用途：了解相关资源；来源访问异常时再查网络与目标网站。
