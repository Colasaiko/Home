核心配置与服务特性

三档线路区别

BitzNet 当前采用分层的线路组合：

  • 边缘访问：广东 IEPL 专线 + 普通国际线路
  • 核心访问：广东 IEPL 专线 + 亚洲优化线路
  • 深度访问：广东 / 上海 IEPL 专线 + 亚洲优化线路

*具体线路组合取决于套餐等级，请注意并不是所有套餐都能使用上海 IEPL 和亚洲优化线路。*

CLIENT ACCESS / 客户端与订阅

BitzNet 当前推荐并支持多种客户端，但第三方客户端的兼容与配置要求近期有更新。

官方推荐方案

BitzNet 当前优先推荐官方客户端；iOS 用户也可以使用 Nextin，以便更及时获得服务配置和后续更新。如果您使用这两款客户端，近期的第三方订阅调整不会产生影响。

Clash 系与 Surge 更新步骤

当前官方仍提供 Clash 系与 Surge 的兼容支持，但必须使用新的订阅获取流程：

  1. 登录 BitzNet 官网
  2. 进入用户首页，点击“激活订阅”
  3. 完成人机验证
  4. 返回客户端重新更新/获取配置
如果更新失败，请重新导入一次订阅链接；并注意不要开启 DNS 覆写，需开启 TUN 模式。

Shadowrocket

Shadowrocket 用户需要按当前官方新版教程重新导入配置，旧的直接通过 URL 导入的方式可能失效。建议先删除旧节点/配置后再重新进行导入。

Quantumult X

Quantumult X 当前需使用“新建关联”方式导入配置；由于官方表示教程仍在完善，若无法顺利完成关联导入，官方建议暂时切换其他客户端。

停止支持的客户端

CFW (Clash for Windows) 与 ClashX 等旧版 Clash 客户端当前已经停止支持，请改用 Bitz Net 官方客户端或其他现代客户端（如 Clash Verge Rev 等）。

其他配置

  • 流媒体支持：三档套餐页面均将流媒体解锁列为服务特性。
  • 设备数量限制：官方标明“不限制本人设备数”，请注意不应进行多人共享。
  • 免费试用信息：当前官方页面标注注册后可获得 24 小时试用 (Free，5GB，相当于核心访问 500Mbps 规格)。
  • 在线客服保障：提供在线客服售后，官方公开客服页面当前标示服务时段为 09:00–23:00，非该时段回复可能较慢。

优点

  1. 细分为边缘、核心、深度三档访问等级，丰俭由人
  2. 提供广东 IEPL，深度访问增加上海 IEPL 选项
  3. 搭配亚洲优化线路（限核心与深度访问）
  4. 流量梯度合理（80GB / 400GB / 1000GB）
  5. 峰值带宽对应分级（100 / 500 / 800 Mbps）
  6. 涵盖季付、半年付、年付、两年付、三年付的完整周期选择
  7. 官方标明流媒体解锁支持
  8. 不限制本人设备数量
  9. 提供 Bitz Net 官方专属客户端，降低使用门槛
  10. iOS 提供优选推荐 Nextin 客户端
  11. 仍提供主流第三方客户端兼容更新方案
  12. 具备在线客服售后
  13. 当前经验证可用 NEW9 获得一次性9折

注意事项

  • NEW9 只能使用1次：当前验证规则为只能使用1次，使用后不能再次使用，并不是无限次循环优惠。
  • NEW9 不是已确认的新人码：第三方资料有提及新用户9折，但当前官方结算页没有明确注明新人专属。
  • NEW9 没有已知截止日期：官方未公布截止时间，不代表永久有效，随时可能调整。
  • BitzNet 最低购买周期为季付：页面显示的约 ¥23.33/月等效金额，只是基于季付总价折算，不代表可以直接按月支付。
  • 三档线路能力不同：请勿认为 80GB 边缘访问套餐也享有上海 IEPL 与 800Mbps 带宽。
  • 峰值带宽不是测速保证：100 / 500 / 800 Mbps 属于官方标称峰值规格，实际结果会受网络环境、节点状态、时间等因素影响。
  • 第三方客户端需要维护：配置规则随时可能更新，优先参考最新官方教程；CFW / ClashX 等旧版客户端已彻底停止支持。
