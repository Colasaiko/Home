# 我的主页 (My Homepage)

为了方便您将网站托管在 GitHub Pages 上并随时更改内容，我已经将所有网站的文字、链接和卡片配置全部抽离到了独立的配置文件中！

## 📂 如何修改内容？

您只需要去 `data/` 文件夹里修改对应的 `.js` 数据文件即可，网页会自动读取这些文件并更新界面：

1. **`data/profile.js`**
   - 修改您的主页大标题（欢迎语）
   - 修改您的个性签名和标签
   - 更改头像图片路径

2. **`data/blogs.js`**
   - 这里存放您的 10 个（或未来增加的）个人博客矩阵。
   - 修改博客名称、添加新博客链接。

3. **`data/communities.js`**
   - 存放您常逛的社区、社交媒体链接（例如 GitHub、B站、少数派等）。
   - 可以自定义这些网站在鼠标放上去时的品牌悬浮颜色和图标。

4. **`data/projects.js`**
   - 修改其他的项目集合（比如导航站点、图库、API 等大卡片）。

## 💡 为什么使用 `.js` 数据文件而不是 `.md`？

因为主页里包含了大量漂亮的“卡片、颜色代码、FontAwesome 图标”。如果使用普通的 Markdown 文件，很难精确控制这些卡片的样式，稍不注意就会导致排版错乱。

使用目前的 `JSON-like JS 对象`：
1. **格式一目了然**，就像填表格一样简单，不会改崩布局。
2. **无需搭建任何服务器**，直接双击 `index.html` 就能在本地预览最新效果（如果使用传统的 fetch 请求本地 json 文件，浏览器会因为跨域安全策略报错）。
3. 完美兼容 GitHub Pages。

享受您的全新极客主页吧！🚀
